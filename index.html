Server Backup

Server Backup is a private, single-user tool that stores encrypted backups of the owner's own work server in the owner's own Google Drive.

It uses the open-source programs restic (encryption and versioning) and rclone (upload). It is not offered to the public and has no other users.

The app requests only the drive.file permission: it can see and change only the files it created itself, not any other files in Google Drive.
