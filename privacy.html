Privacy Policy

Last updated: September 27, 2026

Server Backup is a private tool used by a single person (the owner) to back up the owner's own server to the owner's own Google Drive.

What data the app accesses

The app requests the Google Drive drive.file scope. It can create, read, update and delete only the files and folders that it created itself. It cannot see any other files in Google Drive.

How the data is used

The files are encrypted backup archives of the owner's server. They are uploaded to and read from the owner's Google Drive solely to store and restore backups.

Sharing and storage

No data is sold, shared with or transferred to any third party. The app has no servers of its own and does not collect analytics. Access credentials are stored only on the owner's server.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
